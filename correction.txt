Limiter la taille du body:
	# plus court que 100 octets → 201
	curl -X POST -H "Content-Type: plain/text" --data "BODY IS HERE court" localhost:8080/upload/court.txt

	# plus long que 100 octets → 413
	curl -X POST -H "Content-Type: plain/text" --data "BODY IS HERE et ce texte est beaucoup plus long que la limite de cent octets fixee dans la config, donc refus" localhost:8080/upload/long.txt

	# même texte long sur /grand (limite 1K) → 201 : la location remplace la limite du server
	curl -X POST -H "Content-Type: plain/text" --data "BODY IS HERE et ce texte est beaucoup plus long que la limite de cent octets fixee dans la config, donc refus" localhost:8080/large/long.txt

POST : créer le fichier → 201 (bonjour = 7 octets, d'où Content-Length: 7)

tests avec netcat nc:
	nc 127.0.0.1 8080

	POST : créer le fichier → 201 (bonjour = 7 octets, d'où Content-Length: 7)
	printf 'POST /upload/test.txt HTTP/1.1\r\nHost: localhost\r\nContent-Length: 7\r\n\r\nbonjour' | nc 127.0.0.1 8080
	
	GET : le relire → 200, et le corps affiche bonjour
	printf 'GET /upload/test.txt HTTP/1.1\r\nHost: localhost\r\n\r\n' | nc 127.0.0.1 8080

	DELETE : le supprimer → 204
	printf 'DELETE /upload/test2.txt HTTP/1.1\r\nHost: localhost\r\n\r\n' | nc 127.0.0.1 8080
	
	GET à nouveau → 404 : il n'existe plus
	printf 'GET /upload/test2.txt HTTP/1.1\r\nHost: localhost\r\n\r\n' | nc 127.0.0.1 8080
	
	Les mêmes méthodes, refusées sur / → 405, car / n'autorise que GET :
	printf 'DELETE /index.html HTTP/1.1\r\nHost: localhost\r\n\r\n' | nc 127.0.0.1 8080
	printf 'POST /test.txt HTTP/1.1\r\nHost: localhost\r\nContent-Length: 7\r\n\r\nbonjour' | nc 127.0.0.1 8080

Requêtes inconnues sans aucun crash:
	curl -i -X FOO localhost:8080/                                        # 501 Not Implemented
	printf 'FOO / HTTP/1.1\r\nHost: localhost\r\n\r\n' | nc -q1 localhost 8080   # 501
	printf 'BLABLA\r\n\r\n' | nc -q1 localhost 8080                       # 400 Bad Request
	printf 'GET / HTTP/1.1\r\n\r\n' | nc -q1 localhost 8080              # 400 : Host manquant (obligatoire en HTTP/1.1)
	curl -i localhost:8080/                                               # 200 : le serveur tourne toujours
